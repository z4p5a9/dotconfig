Spawn one or more `web-surfer` sub-agents whenever what you are doing needs current or external web information.

Use it when:

- you need to make sure your understanding is up to date
- the answer may depend on recent information
- you need official docs, standards, release notes, changelogs, announcements, or primary sources
- you need common practices, industry standards, conventions, modern approaches, comparisons, or alternatives
- you need current ecosystem behavior or API behavior outside the local codebase
- you need publication dates, version dates, quotes, source links, or evidence
- you need to verify a claim against reliable web sources

Give each `web-surfer` a specific research target.

If you need to research separate topics, spawn separate `web-surfer` agents for each topic.

If the work depends on current external information, read the `web-surfer` result and the important links or quotes it returns before relying on it.
